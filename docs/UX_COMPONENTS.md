# UX універсальних компонентів Shukayu

Інструкція **поведінки** інтерактивних елементів: коли який контроль, як відкривається / закривається, клавіатура, стани, мобільні винятки.

Візуал (колір, розмір, відступ, радіус) — у [`docs/DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md). Тут їх не дублюємо: якщо конфлікт цифр — править дизайн-система; якщо конфлікт поведінки — цей файл.

Компоненти: `src/shared/ui/`. База — Radix (фокус, aria, портали). Не збирати кастомні меню з `div` + `useState`, якщо вже є відповідний примітив.

**Не входить:** розклад блоків по сторінках (окремий документ композиції). Dark theme.

---

## 1. Принципи взаємодії

1. **Один primary на групу.** Користувач завжди розуміє «головну дію». Друга дія — outline або ghost.
2. **Клік поза / Escape закриває** будь-який overlay (меню, select, popover, dialog, sheet), крім alert-dialog під час небезпечної дії — там backdrop не закриває, лише кнопки або Escape = Cancel.
3. **Не гніздити overlay в overlay.** Dropdown всередині Dialog — так (меню в модалці). Dialog поверх Dialog — ні. Sheet поверх Dialog — ні.
4. **Миттєвий зворотний зв’язок.** Hover/focus ≤ 180ms. Оптимістичний UI для низькоризикових перемикачів (наприклад, «Онлайн для повідомлень»). Помилка — повернути стан + toast.
5. **Hit-area.** Інтерактив не менше 36px desktop / 44px mobile. Дрібний контроль (checkbox 18px) розширюється лейблом на весь рядок.
6. **Клавіатура = миша.** Усе, що відкривається кліком, відкривається Enter/Space з фокусу.
7. **Не сюрпризити навігацією.** Кнопка робить дію. Посилання веде на URL. Картка-лістинг — посилання; вкладені іконки (зберегти, меню) не тригерять перехід.
8. **Текст дії — дієслово.** «Зберегти», «Надіслати пропозицію», «Скасувати». Не «ОК», не «Так» без іменника, якщо дія деструктивна.

## 2. Який контроль обрати

| Потрібно | Контроль | Не використовувати |
|---|---|---|
| Головна / другорядна дія | Button (`default` / `outline` / `ghost`) | Картка або рядок списку як єдина «кнопка» без `href`/`onClick` на явному контролі |
| Перейти на сторінку | Link (або Button `asChild` + Link) | `onClick` + `router.push` на `<div>` |
| Одна опція з короткого фіксованого списку (≤ 12, без пошуку) | Select | Dropdown menu з «вибором», радіо в модалці |
| Одна опція з довгого / пошукового списку (міста) | Combobox (`CityCombobox`) | Select на 100+ пунктах |
| Ієрархія (категорія → підкатегорія) | CascadingSelect | Кілька незалежних Select підряд без зв’язку |
| Команди («Редагувати», «Видалити», «Поділитися») | DropdownMenu | Select (це не вибір значення форми) |
| Права кнопка миші / long-press на рядку | ContextMenu | Лише якщо та сама дія є і в dropdown «⋯» — не ховати критичне тільки в context |
| Увімк / вимк налаштування (зберігається одразу) | Switch + лейбл | Checkbox у списку налаштувань; Toggle-кнопка |
| Позначити кілька в формі / фільтрі | Checkbox (група) | Switch (він про «стан системи», не про «вибрати пункти») |
| Один з кількох у формі | Radio group | Tabs |
| Перемкнути вигляд сторінки (Best matches / Recent) | Tabs | Toggle group, якщо це маршрути або великий контент |
| Компактний вибір виду (сітка/список, день/тиждень) | Toggle group | Tabs |
| Тимчасово «втиснута» опція (bold у редакторі) | Toggle | Switch |
| Підтвердити небезпечне | AlertDialog | Звичайний Dialog з хрестиком як єдиним скасуванням |
| Форма / деталі поверх сторінки | Dialog (desktop), Sheet (mobile `&lt; md`) | Нова сторінка, якщо крок короткий (≤ 6 полів) |
| Фільтри, мобільна навігація, профіль-меню на малому екрані | Sheet (right або bottom) | Dropdown (на мобільному overlay-меню &gt; 5 пунктів → Sheet) |
| Підказка без дії | Tooltip | Dialog |
| Картка-прев’ю при наведенні | HoverCard | лише desktop + `@media (hover: hover)` |
| Довгий контент у секції, FAQ | Accordion (`type="single"`) | купа Collapsible без спільної моделі |
| «Показати ще» в одному блоці (опис, права колонка) | Collapsible або текстовий «more» | Accordion з одним item |
| Діапазон числа / ціни | Slider + поля зліва-справа для точного вводу | Лише слайдер без чисел |

## 3. Кнопки

Файл: `button.tsx`. Варіанти й розміри — дизайн-система §8.1.

### 3.1. Ієрархія

| Рівень | Variant | Коли |
|---|---|---|
| 1. Головна дія екрана / картки | `default` (primary pill) | Apply, Надіслати, Зберегти, Створити запит |
| 2. Альтернатива поруч | `outline` | Save job, See public view, Скасувати в парі з primary |
| 3. Третя / іконкова / в таблиці | `ghost` | Фільтри, Share, ⋯, закрити банер |
| 4. Небезпека | `destructive` або `destructiveOutline` | Видалити, Відхилити, Розірвати угоду |
| 5. Текст-лінк | `link` | «more», «Subscribe now» у банері — не в футері форми |

`secondary` (чорна filled) — рідко: інверсія на світлому промо, не як заміна primary.

### 3.2. Групи

- Порядок desktop: другорядна зліва, primary справа (`Скасувати` → `Зберегти`).
- Мобільний футер форми: primary зверху на 100% ширини, outline під нею на 100%. Gap 8px.
- Іконка ліворуч від тексту. Тільки стрілка «далі» може бути справа.
- Icon-only: обов’язковий `aria-label` (українською в `uk`, англійською в `en`). Tooltip на hover/focus, delay 200ms.

### 3.3. Стани

| Стан | Поведінка |
|---|---|
| Hover | Лише `@media (hover: hover)` |
| Focus-visible | Ring з дизайн-системи; не показувати ring на чистому кліку миші |
| Loading | `disabled`, спінер 16px замість іконки або ліворуч від незмінного тексту. Ширина кнопки не стрибає. Повторний submit заборонений |
| Success на кнопці | Не змінювати лейбл на «Готово» довше ніж 1.2s; краще toast + закрити overlay |
| Disabled | Пояснення поруч або в tooltip, чому неактивна (немає Connects, не заповнена форма) |

Подвійний клік по primary не створює дубль запиту (debounce/in-flight guard на рівні фічі).

### 3.4. Кнопка vs посилання

Якщо URL можна відкрити в новій вкладці — це Link. `target="_blank"` лише зовнішні, з `rel="noopener noreferrer"`. Внутрішні маршрути — завжди клієнтський Link.

## 4. Випадаючі поверхні

Спільне: портал у `body`, `z-50`, offset **8px**, ширина меню ≥ тригера (для Select/Combobox — **рівно ширина тригера**). Max-height 320px, далі внутрішній скрол (`ScrollArea` / `CommandList`). Відкриття: fade + 4px slide, 150–180ms.

Закриття: Escape, клік зовні, вибір пункту-команди, втрата фокусу сторінки. Вибір checkbox-пункту в меню **не** закриває меню (мультивибір). Radio/звичайний item — закриває.

На `&lt; md`, якщо пунктів **більше 6** або є вкладені акаунти / довгі форми — не Dropdown, а **Sheet**.

### 4.1. Dropdown menu (команди)

`dropdown-menu.tsx`. Тригер: ghost/icon кнопка або аватар.

Структура як у кабінетному меню-профілю (принцип Upwork):

1. Шапка (ім’я, план) — не клікабельна або веде на профіль.
2. Рядок зі Switch, якщо це налаштування «зараз» (онлайн, beta-меню).
3. Список команд групами.
4. Separator перед деструктивним / виходом.
5. Вкладений Sub: «Перемкнути акаунт» → список профілів; пункт «ще» не ховає поточний акаунт.

Правила:

- Пункт = іконка 20px + текст. Не обрізати підпис; ellipsis лише після іконки статусу справа.
- Disabled пункт лишається видимим (opacity 0.5) + причина в tooltip.
- Destructive внизу групи, колір destructive, без іконки «смітник» як єдиного сигналу — потрібен текст.
- Subменю відкривається вправо; якщо не вміщається — вліво (Radix collision).
- Не класти в dropdown первинну бізнес-дію екрана («Apply now»).

Клавіатура: `Enter/Space` відкрити, стрілки по пунктах, `Home/End`, `Right` у sub, `Left` назад, `Enter` виконати, `Esc` закрити (sub спочатку, потім корінь). Typeahead по першій літері.

### 4.2. Select (значення форми)

`select.tsx`. Завжди з лейблом. Placeholder — не валідне значення: submit без вибору = помилка поля.

- Шеврон обертається 180° при open.
- Обраний пункт: галочка зліва, фон `accent`.
- Групи (`SelectGroup`) з підписом 12px muted.
- Порожній список неможливий: або skeleton, або disabled trigger.
- Зміна значення оголошується скринрідеру через нативний combobox/listbox Radix — не дублювати live region, якщо немає сайд-ефекту.

Не використовувати Select для навігації по локалях, якщо є окремий патерн у хедері — але якщо вже Select, після зміни одразу застосувати локаль (як зараз), без окремої кнопки «OK».

### 4.3. Combobox (пошук + вибір)

`city-combobox.tsx` + `command.tsx`.

- Відкриття: клік / Arrow Down. Фокус одразу в поле пошуку.
- Пошук з debounce **300–500ms** (зараз 500 — ок для API міст). Поки loading — текст «Пошук…» у списку, не порожня діра.
- Мінімум символів для запиту: **2**. Менше — підказка «Введіть щонайменше 2 символи», не «Not found».
- Not found — один рядок, без фейкових опцій.
- Вибір закриває, підставляє значення в тригер. Clear (якщо дозволено) — іконка X на тригері, не окремий пункт «None», якщо є `clearable`.
- Список: ширина = тригер, `align="start"`.
- `shouldFilter={false}` якщо фільтр на сервері (міста). Клієнтський filter — лише локальні короткі словники.

### 4.4. Cascading select (дерево)

`cascading-select.tsx`. Категорії послуг.

- Корінь показує перший рівень. Пункт з дітьми: шеврон; клік по шеврону/рядку з дітьми **розгортає** гілку, не обирає батька, якщо батько не є валідним кінцевим значенням.
- Якщо батько теж можна обрати (загальна категорія) — окрема дія: клік по назві = select, клік по шеврону = expand. Не змішувати в один клік.
- Обраний шлях видно в тригері: `Батько / Дитина` (ellipsis посередині при переповненні).
- Open: авторозгорнути гілку до поточного `value`.
- Clear — якщо `clearable`, не закривати дерево посередині вибору.
- Мобільний: те саме Popover ок, доки глибина ≤ 3 і список короткий; інакше Sheet з «Назад».

### 4.5. Popover, Hover card, Tooltip

| | Відкриття | Закриття | Клікабельність всередині |
|---|---|---|---|
| Popover | клік / Space | клік зовні, Esc, повторний клік по тригеру | так (фільтри, дата) |
| HoverCard | hover 300ms або фокус | mouseleave з grace 200ms, Esc | так, курсор може зайти в картку |
| Tooltip | hover 200ms або фокус | mouseleave одразу, Esc | ні — якщо потрібна дія, це HoverCard або Dialog |

Tooltip не на touch. На мобільному ті самі підказки — `aria-label` або видимий підпис, не tooltip.

Не вішати tooltip на disabled кнопку (в DOM disabled не фокуситься): обгорнути в `span` з tooltip, або пояснити текст поруч.

### 4.6. Context menu, Command palette, Menubar, Navigation menu

- Context menu дублює ⋯-меню рядка. На мобільному long-press 500ms **або** тільки ⋯ (long-press легко конфліктує зі скролом — пріоритет кнопці ⋯).
- Command: `⌘K` / `Ctrl+K` опційно пізніше; зараз Command живе всередині combobox. Якщо з’явиться глобальна палітра — один інстанс, закриває інші overlay.
- Menubar — лише складна десктоп-шапка з кількома меню; публічний хедер Shukayu — Navigation menu або прості Link.
- Navigation menu: hover-open на desktop з delay 100ms; на мобільному — не mega-menu, а Sheet з акордеоном розділів.

## 5. Списки

### 5.1. Меню-список (пункти overlay)

- Один стовпчик. Групи через Separator + опційний заголовок групи 12px muted, padding 8×12, не клікабельний.
- Висота пункта 36px. Немає «порожніх» розділювачів підряд.
- Скрол тільки всередині списку, не на всю сторінку. Скрол не закриває меню.

### 5.2. Лістинг сутностей (запити, пропозиції)

Картка — `listing-card` з дизайн-системи. UX:

- Ціла картка = посилання на деталі (`<a>` або Next Link обгортка). Hover курсор pointer, бордер сильнішає.
- Вкладені контроли (`Save`, thumbs down, ⋯): `type="button"`, зупиняють навігацію. Фокус окремий, видимий ring.
- Клавіатура по лістингу: Tab по картці як по одному лінку, потім по вкладених кнопках (не skip).
- «more» в описі: розгортає текст **на місці** (Collapsible), не веде на деталі. Повторний клік — «less». Не обидва: і «more», і клік по картці з різними цілями без пояснення — «more» має `stopPropagation`.
- Пагінація / infinite: не змішувати. Для кабінетного лістингу — пагінація (universal-pagination). Infinite — лише стрічки на кшталт чату.
- Завантаження наступної сторінки не скидає скрол і не замінює список порожнім skeleton (skeleton — лише перший load).
- Порожній список: патерн Empty з дизайн-системи + одна дія («Створити запит» / «Зняти фільтри»).

### 5.3. Таблиця (адмінка, щільні дані)

- Рядок hover. Клік по рядку — деталі **або** чекбокс-вибір, не обидва без явної колонки дій.
- Сортування: клік по header, індикатор стрілки, `aria-sort`.
- Горизонтальний скрол на мобільному; перша колонка (ім’я) може бути sticky.
- Bulk-дії з’являються лише коли є selected ≥ 1; бар над таблицею, не замість header.

### 5.4. Віртуальні / довгі списки в overlay

Select/Command &gt; 50 пунктів — скрол зверху-знизу (вже є scroll buttons у Select). Не рендерити 1000 DOM-нод без віртуалізації; для міст пошук обов’язковий.

## 6. Розгортання

### 6.1. Accordion vs Collapsible vs «more»

| | Accordion | Collapsible | Текстовий more |
|---|---|---|---|
| Кілька секцій, одна відкрита (FAQ, налаштування групами) | `type="single"` `collapsible` | ні | ні |
| Кілька секцій одночасно | `type="multiple"` | ні | ні |
| Один блок «деталі» в картці / сайдбарі | ні | так | ні |
| Обрізаний абзац (2–3 рядки) | ні | можна | так, якщо немає вкладених контролів |

Анімація висоти 180–200ms (`accordion-down/up`). Шеврон 16px справа, rotate 180. Тригер — увесь рядок, не лише іконка.

Не анімувати, якщо `prefers-reduced-motion: reduce` — миттєвий open/close.

FAQ: `type="single"`, щоб не роздувати сторінку. Кабінетні секції (Preferences, Proposals) — `type="multiple"` або статичні блоки; не змушувати відкривати, щоб побачити головне.

### 6.2. Вкладені розгортання

- Дерево категорій у CascadingSelect — єдине місце вкладеного expand у формі.
- Не класти Accordion всередині Accordion. Collapsible всередині Accordion — лише для «ще N пунктів».
- Розгорнутий стан не зберігати в URL, окрім якщо це таб/якір (тоді Tabs або hash, не accordion).

### 6.3. Читати повністю (опис джоби / профілю)

Початково 3 рядки (`line-clamp-3`). Контрол «more» / «менше» — `button` variant `link`, 14/600, primary. Після розгортання скрол не стрибає. На скрінрідері: `aria-expanded`.

## 7. Перемикачі та вибір

### 7.1. Switch

`switch.tsx`. Для **миттєвих** налаштувань: «Онлайн для повідомлень», «Beta: нове меню», підписка на лист.

- Лейбл зліва, switch справа в рядку (як у меню Upwork) **або** лейбл справа від switch у формах — **у меню кабінету завжди: текст зліва, control справа**.
- Клік по всьому рядку (не лише по thumb).
- Стан `checked` = увімкнено = primary track.
- Не вимагати «Зберегти» після Switch у settings-списку. Optimistic + toast лише якщо запит упав.
- Не використовувати Switch для «згоден з офертою» — це Checkbox (свідомий одноразовий акт).

Клавіатура: фокус на switch, Space перемикає. У рядку меню — фокус на рядку, Space не відкриває підменю.

### 7.2. Checkbox і Radio

- Checkbox: незалежні опції, фільтри, «вибрати всі» в таблиці (indeterminate, коли частина).
- Radio: взаємовиключні в одній групі, ніколи один radio.
- Лейбл клікабельний (`htmlFor` / обгортка).
- Помилка групи — під групою, не під кожним пунктом.
- «Вибрати всі» змінює лише видиму сторінку або явно підписує «усі N на цій сторінці».

### 7.3. Toggle і Toggle group

- Toggle — форматування / «втиснуто зараз», не збережене налаштування (для збереженого — Switch).
- Toggle group: `type="single"` для виду (список/сітка). Не залишати групу без вибраного, якщо значення обов’язкове.
- Active: візуал з дизайн-системи (білий сегмент у muted track), `aria-pressed`.

### 7.4. Tabs

`tabs.tsx`. Зміна вкладки **не** повинна втрачати введені дані сусідньої вкладки (розмонтовувати обережно). Якщо таб = окремий URL (`/profile` reviews vs settings) — це навігація (Link зі стилем таба), не Radix Tabs без адреси.

- `Arrow Left/Right` між табами, `Tab` іде в контент.
- Disabled таб: іконка lock + tooltip чому.
- Кількість табів на мобільному: горизонтальний скрол рядка, не перенос у дві лінії. Активний таб скролиться в зону видимості.

Не використовувати Tabs для stepper («крок 1 з 3») — окремий індикатор прогресу + Back/Next.

## 8. Модалки та панелі

### 8.1. Dialog

Форми середньої довжини, прев’ю, «написати повідомлення».

- Відкриття блокує скрол body (Radix). Фокус у перше поле або заголовок.
- Close: X, Esc, клік backdrop. Якщо форма **брудна** — спочатку AlertDialog «Відкинути зміни?», не мовчки закрити.
- Після закриття фокус повертається на тригер.
- Одна primary в футері. Не сабмітити по Enter у textarea (Enter = новий рядок); Enter в input — сабміт форми ок.

### 8.2. Alert dialog

Незворотні дії: видалити, відхилити, скасувати угоду.

- Немає X. Backdrop клік **не** закриває.
- Esc = Cancel (безпечний вихід).
- Destructive кнопка справа (desktop). Назва кнопки повторює дію: «Видалити запит», не «Підтвердити».
- Немає input, окрім короткого «введіть назву щоб підтвердити» для критичного (акаунт). За замовчуванням — ні.

### 8.3. Sheet і Drawer

| | Sheet | Drawer |
|---|---|---|
| Desktop | права панель фільтрів / деталей 400px | не використовувати |
| Mobile | навігація, меню профілю, фільтри | bottom sheet для короткого вибору (2–7 опцій) |

Swipe-down закриває drawer. Sheet: Esc + backdrop + X. Не обрізати футер з CTA — sticky footer в панелі, скролиться лише контент.

Мобільне меню кабінету (аватар): Sheet з тими ж пунктами, що desktop dropdown (§4.1), включно зі Switch.

### 8.4. Toast vs Alert vs Empty vs Dialog помилки

| Сигнал | Куди |
|---|---|
| Короткий успіх / невдача запиту | Toast 5s, можна закрити |
| Помилка поля | Під інпутом, не toast |
| Сторінка не завантажилась | Error block + Retry |
| Немає даних | Empty |
| Потрібне рішення користувача | Dialog / AlertDialog |
| Промо | Banner (dismissible, пам’ятати в localStorage) |

Не дублювати одне повідомлення в toast і в alert одночасно.

## 9. Клавіатура і фокус (зведення)

| Контрол | Відкрити | Рух | Вибрати | Закрити |
|---|---|---|---|---|
| Button | — | Tab | Enter / Space | — |
| Dropdown / Context | Enter, Space, (context: Shift+F10) | ↑ ↓ Home End | Enter | Esc |
| Select | Enter, Space, Alt+↓ | ↑ ↓, typeahead | Enter | Esc |
| Combobox | Enter, ↓ | ↓ у список, друк у полі | Enter | Esc |
| Tabs | — | ← → | авто при фокусі або Enter (залишаємо авто Radix) | — |
| Switch / Checkbox | — | Tab | Space | — |
| Radio group | — | ← → ↑ ↓ | Space / стрілка | — |
| Accordion | — | Tab по тригерах | Enter / Space | повтор |
| Dialog | — | Trap Tab | — | Esc |
| AlertDialog | — | Trap Tab | — | Esc = cancel |
| Slider | — | ← → Home End | — | — |

Focus trap лише в Dialog / AlertDialog / Sheet / Drawer. Dropdown і Select — фокус у списку, повернення на тригер після закриття.

Видимий focus-ring **завжди** для клавіатури, ніколи `outline-none` без заміни.

## 10. Мобільні винятки (`&lt; md`)

- Dropdown з &gt; 6 пунктів або з Switch + вкладеними акаунтами → Sheet.
- Select залишається Select (нативний feel Radix ок), Combobox — Popover на всю ширину екрана мінус gutters 16px.
- Hover й HoverCard вимкнені. Замість hover-прев’ю — окремий тап на деталі.
- Кнопки груп форм — колонка 100%.
- Tabs — горизонтальний скрол.
- Tooltip немає; підпис видимий або `aria-label`.
- Bottom nav 56px не перекриває FAB/primary: остання кнопка сторінки + padding-bottom ≥ 72px, якщо rail знизу.
- Жести: swipe між табами **не** робити (конфлікт зі скролом і браузерним back). Swipe лише для Drawer і каруселі.

## 11. Доступність (мінімум)

- У кожного інтерактивного без видимого тексту — `aria-label`.
- Відкритий overlay: `aria-expanded` на тригері, `role` від Radix не знімати.
- Живі повідомлення (toast, помилка сабміту форми зверху) — `aria-live="polite"`; помилка сабміту з фокусом на першому invalid полі.
- Контраст і розміри — дизайн-система. Не класти сірий текст 12px як єдиний статус кнопки.
- Не ховати фокус `tabIndex={-1}` на видимих кнопках.
- Мова інтерфейсу контролів збігається з локаллю сторінки (не змішувати «Close» / «Закрити» в одній оболонці).
