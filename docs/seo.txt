3. Аналіз он-пейдж SEO
3.1 Тег Title
Поточний тайтл: “Головна | Shukayu”, довжина 17 символів (короткий)
❌️ Потрібно виправити
Тайтл надто короткий і загальний. Він не містить релевантних ключових слів, які могли б залучати користувачів через пошук. Для сторінки платформи для покупців і продавців, кращим був би опис, який більш чітко відображає функції і користь, наприклад:

Платформа для покупців та продавців | Shukayu
Це допомагає пошуковим системам правильно індексувати сторінку та покращує клікабельність за рахунок більш інформативного заголовку. Співпадіння з Description та H1 необхідне для кращої семантичної узгодженості.

3.2 Мета опис
Поточний опис: “Платформа для поєднання покупців і продавців”, довжина 44 символи (короткий)
❌️ Потрібно виправити
Опис також дуже короткий та загальний. Опис повинен охоплювати унікальні торгові пропозиції, ключові переваги або основні функції:

Платформа Shukayu — ефективний сервіс для поєднання покупців і продавців для надійних покупок та продажів.
Це дозволить підвищити релевантність і привабливість посилу для користувачів у снипетах Google. Також слід забезпечити відповідність ключових слів у тайтлі та H1.

3.3 Тег H1

✅ Статус OK
H1 має виразний заклик до дії і відображає суть сайту. Проте покращити можна зробити коротшим – 2-4 слова для кращої SEO-фокусованості. Варіант:

Скажи, що хочеш
Важливо, щоб H1 залишався релевантним до Title та Description і містив ключові слова, пов’язані з платформою для покупців і продавців.

Поточне слабке представлення тем і відсутність списків, таблиць і покрокових інструкцій знижує якість структури та ускладнює пошуковим системам розуміння змісту. Приклад для покращення:

Робіть акцент на тематичній оптимізації в усьому тексті.

4. Технічне SEO
4.1 Meta Robots
Поточне значення: порожнє (відсутній тег)
❌️ Потрібно додати
Рекомендовано додати тег meta robots, наприклад:

<meta name="robots" content="index, follow">
Це підтвердить пошуковикам, що сторінку треба індексувати і слідувати за посиланнями.

4.2 Канонічний тег
Поточне значення: відсутній
❌️ Потрібно додати
Канонічний тег допомагає уникнути дублюючих URL в індексі пошукових систем. Приклад для головної сторінки:

<link rel="canonical" href="https://shukayu.com.ua/">
4.3 Hreflang
Мови сайту відсутні (відсутній тег hreflang)
❌️ Потрібно додати, якщо є версії іншими мовами
Якщо сайт підтримує кілька мов, потрібно вказати тег hreflang для коректної мови орієнтації користувача.

4.4 Оптимізація зображень
Кількість зображень: 0
Зображення з alt-текстом: 0
❌️ Потрібно додати оптимізовані зображення
На сторінці відсутні зображення, або вони не знайдені. Рекомендується додати ілюстрації з описовими alt-текстами з ключовими словами, що покращує SEO і доступність.

4.5 HTML теги
Inline CSS: 5
JS теги: 31
❌️ Потрібно перевірити використання inline стилів
Занадто багато inline CSS і JS може погіршувати швидкість. Рекомендується мінімізувати inline CSS, оптимізувати скрипти, винести стилі у зовнішні файли.

4.6 Вихідні посилання

Зовнішніх: 0

❌️ Потрібно усунути дублікатні посилання та додати зовнішні посилання
Усунення дублікатів оптимізує передачу вагою сторінки. Зовнішні посилання на авторитетні джерела зміцнять довіру і авторитет сайту.

5. Структуровані дані та схема
Відсутні схеми WebSite, BreadcrumbList, Organization, SearchAction
❌️ Потрібно додати
Для головної сторінки платформи рекомендується додати такі схеми:

{
"@context": "https://schema.org",
"@type": "WebSite",
"url": "https://shukayu.com.ua/",
"potentialAction": {
"@type": "SearchAction",
"target": "https://shukayu.com.ua/search?q={search_term_string}",
"query-input": "required name=search_term_string"
}
}
{
"@context": "https://schema.org",
"@type": "Organization",
"name": "Shukayu",
"url": "https://shukayu.com.ua/",
"logo": "https://shukayu.com.ua/logo.png",
"contactPoint": {
"@type": "ContactPoint",
"telephone": "+380XXXXXXXXX",
"contactType": "customer service"
}
}
Це покращить індексацію, позначить компанію, додасть пошукові функції.
